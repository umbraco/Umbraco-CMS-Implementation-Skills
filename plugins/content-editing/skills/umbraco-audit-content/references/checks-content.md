# Checks: answers, claims, freshness, meta versus body

The editorial half of the audit. These checks are judgement, so label them as such in the report
and quote the passage each finding is about.

| Check | Finding when | Not a finding |
|---|---|---|
| Meta versus body | The meta description promises something the body does not cover, or misses the page's main point. Quote both | Wording differs but the promise holds |
| Main answer | The question the page exists to answer (from its title, the user's brief or the search evidence) is not answered clearly near the top | The answer is there but further down: suggest moving it (Medium at most) |
| Claims | A factual claim (numbers, customers, capabilities, prices) with no source on the page or from the user | Opinion or experience clearly framed as such |
| Freshness | A date, offer, version or event that has passed; "new" for something that is not | An old publication date on content that is still correct |
| Thin content | The page fails to answer what its title and description promise | A short page that does its job (a contact page, a simple product variant) |
| Overlap | Two pages in scope answer the same question for the same reader | Two pages on one topic for different readers or stages |

## Rules

- **Word count is not quality.** Use it only to spot pages worth reading closely.
- **Read before recommending.** Never propose adding a section the page already has.
- **Separate a missing answer from a missing fact.** A missing answer is a writing fix; a missing
  fact needs a source from the user. Say which.
- **Don't prescribe formats.** No mandatory FAQ blocks, keyword quotas or schema that does not fit
  the visible content. Answer-engine readiness is clear answers, scoped claims and sources; no
  format guarantees a citation.
- **Overlap is a hypothesis without search data.** Call it possible overlap unless search evidence
  shows both pages competing for the same queries.
